# Noto Sans Thai font

`NotoSansThai-Regular.ttf` is bundled so the server can burn Thai-language
watermark text into PDFs (via `pdf-lib` + `@pdf-lib/fontkit`) without a
network fetch at request time.

- Source: Google Noto Fonts, "Noto Sans Thai" (Regular weight)
- License: SIL Open Font License, Version 1.1 — https://openfontlicense.org/
- The OFL permits bundling, embedding and redistribution of the font,
  including as part of generated documents.
